# Results copied from the FINAL ATR source archive

These compact text artifacts are transcribed from `agentic_error_propagation_results - Copy.zip`.

- `final_comparison.csv`: comparison of independent and propagation conditions across base error rates.
- `multi_seed_summary.csv`: eight summary rows from the 24,000-row multi-seed results file.
- `validation_report.json`: the archive's row/schema validation report, with an explicit note that it has not been rerun here.
- `environment_verification.json` and `gpu_verification.json`: environment claims recorded in the archive, not a fresh environment test.

The raw CSVs, figures, and full logs are still in the supplied ZIP and have not all been uploaded here. Do not treat these summary files as the HotpotQA verifier experiment: they use `error_rate`, `model`, `stage_errors`, and `workflow_failed`, with independent/propagation conditions.

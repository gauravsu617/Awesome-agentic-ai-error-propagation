# GitHub Implementations

This repository includes exactly five GitHub implementations relevant to agentic AI, research automation, retrieval, tool use, and reliability evaluation.

## 1. AgentBench

**Description:**
Official implementation of the AgentBench benchmark for evaluating LLM agents across multiple interactive environments.

**GitHub:**
https://github.com/THUDM/AgentBench

**Relevant research:**
AgentBench: Evaluating LLMs as Agents

---

## 2. Mind2Web

**Description:**
Official implementation and resources for the Mind2Web dataset and generalist web-agent research.

**GitHub:**
https://github.com/OSU-NLP-Group/Mind2Web

**Relevant research:**
Mind2Web: Towards a Generalist Agent for the Web

---

## 3. SELF-RAG

**Description:**
Official implementation of Self-RAG, which combines retrieval, generation, and self-reflection for improved factuality and reliability.

**GitHub:**
https://github.com/AkariAsai/self-rag

**Relevant research:**
Self-RAG: Learning to Retrieve, Generate, and Critique through Self-Reflection

---

## 4. WebShop

**Description:**
Official implementation of the WebShop interactive environment for evaluating grounded language agents.

**GitHub:**
https://github.com/princeton-nlp/WebShop

**Relevant research:**
WebShop: Towards Scalable Real-World Web Interaction with Grounded Language Agents

---

## 5. AgentDojo

**Description:**
An evaluation environment for studying prompt-injection attacks and defenses in tool-using LLM agents.

**GitHub:**
https://github.com/ethz-spylab/agentdojo

**Relevant research:**
AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents

---

## Relevance to Error Propagation

These implementations provide practical environments for studying different failure points:

| Implementation | Main Research Area            |
| -------------- | ----------------------------- |
| AgentBench     | Agent evaluation              |
| Mind2Web       | Web-agent interaction         |
| SELF-RAG       | Retrieval and self-reflection |
| WebShop        | Grounded web interaction      |
| AgentDojo      | Agent security and robustness |

Together, they provide practical starting points for experimenting with multi-step agent reliability and error detection.

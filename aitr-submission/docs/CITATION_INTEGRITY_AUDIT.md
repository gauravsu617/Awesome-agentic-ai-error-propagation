# Citation Integrity Audit Checklist

## Purpose

This checklist describes the minimum evidence needed to audit citations in the research manuscript. It is a checklist, not a completed citation-by-citation verification report.

## Checks to complete

- Confirm each reference exists using a publisher page, DOI landing page, arXiv record, or official proceedings page.
- Verify title, authors, year, venue, volume/pages, and DOI or URL against the primary record.
- Confirm the cited source supports the specific claim attached to it, rather than merely being topically related.
- Check that every in-text citation has a bibliography entry and every bibliography entry is used appropriately.
- Verify that each source version is identified where preprint and proceedings versions differ.
- Record broken links, metadata mismatches, unsupported claims, and corrections in a traceable table.
- Preserve the reviewer/date/status for each checked citation.

## Evidence in the supplied package

The supplied FINAL ATR archive includes a citation-verification spreadsheet named Part_A_Citation_Verification.xlsx, citation-map images, and RIS exports. The spreadsheet's individual rows and the underlying sources must be inspected before a result can be described as verified. The archive listing alone does not establish that the audit is complete.

## Status labels

- **VERIFIED** — checked against the primary bibliographic record and the source's relevant claim/evidence.
- **PARTIAL** — bibliographic metadata was checked, but claim support was not established.
- **MISMATCH** — a material metadata or claim-support discrepancy was found.
- **UNKNOWN / NOT CHECKED** — no sufficient check evidence has been recorded.

Do not report an overall citation-verification percentage unless it is calculated from documented row-level checks. Do not invent source checks or findings.

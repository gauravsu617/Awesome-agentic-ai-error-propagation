# Phase VI — Human–AI Activity Log Guide

**Source:** `Phase_VI_Complete_Package.zip` inside `FINAL ATR(1).zip`.

The nested package contains an AI-use and research-integrity report, checklist, and human–AI activity-log template. The template is a starting point, not proof of the activities recorded in it.

## Log each activity with
- actual date/time and tool/model;
- prompt or action summary;
- AI suggestion/output and the human decision to accept, edit, or reject it;
- verification performed and the evidence path;
- actual outcome and status.

## Integrity rules
- Do not invent dates, prompts, tool versions, errors, commits or outcomes.
- Reconcile approximate entries with the actual prompt/chat history and repository history.
- A notebook/script is not proof it ran; retain execution logs.
- A reported result requires raw data, evaluator output and provenance.
- A claimed fix should be supported by the actual diff or traceback.
- Confirm institution-specific AI-use disclosure rules before submission.

## Required reconciliation
- [ ] Verify dates, tool/model names and actual actions.
- [ ] Record the real branch, commit, files changed and commands run.
- [ ] Link experiment claims to raw outputs and evaluator results.
- [ ] Document human decisions and rejected/modified suggestions.
- [ ] Confirm the final disclosure accurately describes work performed.

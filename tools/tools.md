# Tools and Libraries

This repository includes exactly five tools/libraries useful for developing, orchestrating, evaluating, and studying agentic AI workflows.

## 1. LangChain

**Purpose:** LLM application and agent development

LangChain provides components for building language-model applications, including agents, retrieval, tools, memory, and workflow integrations.

**Official Website:**
https://www.langchain.com/

**GitHub:**
https://github.com/langchain-ai/langchain

---

## 2. LlamaIndex

**Purpose:** Data and retrieval integration

LlamaIndex provides tools for connecting LLM applications with external data and building retrieval-augmented and agentic workflows.

**Official Website:**
https://www.llamaindex.ai/

**GitHub:**
https://github.com/run-llama/llama_index

---

## 3. LangGraph

**Purpose:** Stateful agent orchestration

LangGraph supports graph-based and stateful workflows for building agents that require persistence, control flow, and human-in-the-loop interactions.

**Official Website:**
https://www.langchain.com/langgraph

**GitHub:**
https://github.com/langchain-ai/langgraph

---

## 4. AutoGen

**Purpose:** Multi-agent application development

AutoGen is an open-source framework for building applications involving multiple interacting agents, tools, and humans.

**GitHub:**
https://github.com/microsoft/autogen

**Research Paper:**
https://arxiv.org/abs/2308.08155

---

## 5. DSPy

**Purpose:** Programming and optimization of LM pipelines

DSPy provides a programming framework for building and optimizing modular language-model pipelines.

**GitHub:**
https://github.com/stanfordnlp/dspy

**Paper:**
https://arxiv.org/abs/2310.03714

---

## Tool Selection

These tools represent different aspects of the agentic research workflow:

| Tool       | Main Function               |
| ---------- | --------------------------- |
| LangChain  | Agents and LLM applications |
| LlamaIndex | Data and retrieval          |
| LangGraph  | Stateful workflows          |
| AutoGen    | Multi-agent systems         |
| DSPy       | LM pipeline optimization    |

These tools can be used to construct experimental workflows in which intermediate outputs are logged and evaluated for error propagation.
